# CropFlow P1 Entrypoints

本文件用于为 `docs/planning/P1/` 提供二级入口摘要，帮助新 session 先判断当前样板闭环推进到了哪里，再决定是否进入长文档细读。

## 适用场景

```text
1. 你要接手当前杂草样板闭环的推进工作。
2. 你需要快速知道 P1 哪些事项已经冻结、哪些还没做完。
3. 你需要区分“项目级计划”与“当前样板闭环推进状态”。
```

## 阅读收益

```text
1. 明确 P1 当前是否还在契约冻结阶段，还是已经可以转向实现准备。
2. 明确哪些已确认事项不必重复讨论。
3. 明确后续应该优先补哪个缺口。
```

## 子文档说明

### `docs/planning/P1/todo-list.md`

适合场景：

```text
1. 你想先看当前 P1 的已确认口径、待产出项和完成判定。
2. 你需要最快知道“下一步最该做什么”。
3. 你需要知道当前样板闭环还差哪些核心事项才能进入下一阶段。
```

读它能获得：

```text
1. 已确认的杂草主线业务口径。
2. 当前仍待完成的文档同步、前端原型、验收标准和待决事项。
3. 当前阶段的建议执行顺序和完成判定。
```

使用提示：

```text
如果只想恢复当前进展，先读它，再决定是否需要进入植保清单或大文档。
```

### `docs/planning/P1/植保清单.md`

适合场景：

```text
1. 你要看杂草主线每个任务项的业务描述和接口依赖。
2. 你要回看土壤封闭、药前调查、茎叶除草、药后调查、补防、服务评价的链路定义。
3. 你要核对某个具体农事在当前口径下应该如何触发和往后走。
```

读它能获得：

```text
1. 杂草主线的分步业务说明。
2. 每个任务项的触发条件、接口依赖、系统动作和后续操作。
3. 对比正式 workflow/字段文档时的业务原始语义参考。
```

使用提示：

```text
这是业务清单式文档，适合看语义和链路，不适合拿来当最终字段或对象契约。
如果要看正式对象承接、字段草案或接口收口，回到 plant-protection.md 和 docs/api/weed_diagnosis_api.md。
```

## 建议阅读顺序

```text
1. 先读 docs/planning/P1/todo-list.md
2. 如果要补业务语义或核对具体任务链路，再读 docs/planning/P1/植保清单.md
3. 如果要补正式对象和字段映射，再跳到 docs/planning/team-work-division/plant-protection.md
4. 如果要核对最新接口字段，再读 docs/api/weed_diagnosis_api.md
```
