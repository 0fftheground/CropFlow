# 施肥服务 API 接口文档

## 概述

本文档描述施肥服务中算法接口。

| 项目 | 说明 |
|------|------|
| 服务名称 | fertility_split（施肥算法） |
| 默认地址 | `http://{host}:8090` |
| 协议 | HTTP |
| 请求格式 | `Content-Type: application/json` |
| 在线文档 | 启动服务后访问 `/docs`（Swagger UI） |


### 通用响应约定

| HTTP 状态码 | 说明 |
|-------------|------|
| 200 | 请求成功（部分接口业务失败时 HTTP 仍为 200，需看 `code` 字段） |
| 400 | 请求参数或业务校验失败 |
| 404 | 文件不存在 |
| 422 | 请求体 JSON 格式或字段类型不符合 Pydantic 校验 |
| 500 | 服务端内部错误 |

参数校验失败（422）统一格式：

```json
{
  "code": 422,
  "msg": "参数错误",
  "url": "http://host:8090/xxx",
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "geojson"],
      "msg": "Field required"
    }
  ]
}
```

## 1. POST /run — 施肥处方计算

根据采样点土壤检测数据，计算每个采样点的 N/P/K 施肥推荐方案。该接口是后续空间化接口（处方图、氮素值）的数据来源。

**源文件：** `api/endpoints/fertilizer.py`

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| waysType | string | 是 | 施肥方式，见[附录 waysType](#附录-waysType) |
| targetYield | number | 是 | 目标产量（kg/亩） |
| varietyType | string | 是 | 品种类型，见[附录 varietyType](#附录-varietyType) |
| riceType | string | 是 | 稻作类型，见[附录 riceType](#附录-riceType) |
| fertilizerA | string | 否 | 肥料 A 的 N-P-K 比例，格式如 `46-0-0` |
| fertilizerB | string | 否 | 肥料 B 的 N-P-K 比例，格式如 `18-46-0` |
| fertilizerC | string | 否 | 肥料 C 的 N-P-K 比例，格式如 `0-0-60` |
| excelData | array | 是 | 采样点表格数据，对象数组，见下方字段说明 |

**fertilizerA/B/C 说明：**

- 格式为 `N-P-K` 整数百分比，如 `46-0-0` 表示含氮 46%、磷 0%、钾 0%
- 三项均为空或 `0-0-0` 时，系统自动使用默认肥料：磷酸二铵（18-46-0）、尿素（46-0-0）、氯化钾（0-0-60）

**excelData 每行字段：**

| 列名 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| 采样点ID | string | 是 | 采样点唯一标识，与后续接口 samplePointData 对应 |
| 经度 | number | 是 | WGS84 经度 |
| 纬度 | number | 是 | WGS84 纬度 |
| 国标PH | number | 是 | 土壤 pH 值 |
| Buffer PH | number | M3/healthy | Buffer pH 值 |
| 有机质（%） | number | 是 | 有机质含量 |
| 有效磷-M3 | number/string | 是 | 有效磷 |
| 有效钾-M3 | number/string | 是 | 有效钾 |
| 有效钙-M3 | number/string | M3/healthy | 有效钙 |
| 有效镁-M3 | number/string | M3/healthy | 有效镁 |
| 碱解氮 | number | soil | 碱解氮（测土配肥需要） |

> 其他列（如 `序号`、`有效钠-M3` 等）可存在但不会被解析使用。

### 请求示例

```json
{
  "waysType": "M3",
  "targetYield": 400,
  "varietyType": "0",
  "riceType": "4",
  "fertilizerA": "46-0-0",
  "fertilizerB": "18-46-0",
  "fertilizerC": "0-0-60",
  "excelData": [
    {
      "序号": 1,
      "采样点ID": "344ecfb3-bc70-4597-aa36-74d9f3b6738c",
      "经度": 112.81626886681644,
      "纬度": 28.14154798144474,
      "碱解氮": 0,
      "国标PH": 4.63,
      "Buffer PH": 6.52,
      "有机质（%）": 2.33,
      "有效钾-M3": "77.982",
      "有效钙-M3": "836.214",
      "有效镁-M3": "70.999",
      "有效磷-M3": "12.084"
    }
  ]
}
```

**data 数组元素字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| sectionId | string | 采样点 ID |
| sectionCropsId | string | 作物 ID，固定为 `"0"` |
| nRatio / pRatio / kRatio | object | N/P/K 在基肥、分蘖肥、穗肥的分配比例 |
| avgData | object | 推荐 N/P/K 总量，`avgOfN`/`avgOfP`/`avgOfK`，格式 `{数值}_kg/亩` |
| project | array | 各生育期施肥方案，见[附录 fertilizerType](#附录-fertilizerType) |
| NPK | array | N/P/K 元素对应的肥料名称，供处方图接口解析 |

### 错误响应

| HTTP | code | msg 示例 | 说明 |
|------|------|----------|------|
| 200 | 1 | `flag参数错误,应为 soilFormalLnb` | waysType 与内部 flag 不匹配 |
| 400 | 400 | `缺少必填字段` | waysType / varietyType / riceType 缺失 |
| 400 | 400 | `varietyType 参数错误，当前值为：x` | 枚举值不合法 |
| 400 | 400 | `解析 excelData 失败: ...` | excelData 格式错误 |
| 500 | 500 | `施肥处方计算失败: ...` | 服务端异常 |

## 附录

### 附录 waysType

| 前端值 | 说明 | 内部 flag |
|--------|------|-----------|
| `soil` | 测土配肥 | `soilFormalLnb` |
| `healthy` | 健康施肥 | `healthyFormalLnb` |
| `M3` | 精准施肥-M3 | `precisionFertilizationLnb` |

### 附录 varietyType

| 前端值 | 说明 | 后端编码 |
|--------|------|----------|
| `0` | 籼稻 | XD |
| `1` | 粳稻 | GD |
| `2` | 杂交稻（籼粳交） | ZJD |

### 附录 riceType

| 前端值 | 说明 | 后端编码 |
|--------|------|----------|
| `3` | 双季晚稻 | WD（晚稻） |
| `4` | 早稻 | ZD |
| `5` | 一季晚稻 | WD（晚稻） |
| `6` | 中稻 | YJD（一季稻） |
| `8` | 再生稻 | ZSD |

### 附录 fertilizerType

| 值 | fertilizerTypeName | 说明 |
|----|-------------------|------|
| `0` | 基肥 | 基肥期施肥方案 |
| `1` | 分蘖肥 | 分蘖期施肥方案 |
| `2` | 穗肥 | 穗肥期施肥方案 |

**project[].fertilizerList[] 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 肥料名称，如 `尿素`、`磷酸二铵` |
| amount | string | 推荐用量，如 `7.2_kg/亩` |
| ratio | string | N-P-K 比例，如 `46-0-0` |
| unit | string | 单位，固定为 `kg` |
