3 某一自然年内任意区间范围内积温积雨列表数据查询接口
3.1 接口描述
根据经纬度，查询某自然年内任意区间范围内，指定起始温度的积温积雨数据接口。
3.2 接口URL
 https://iland-t.zoomlion.com/open-sharing-platform/zlapi/weather/v1/getIntervalTempAndRainfallList
3.3 	请求头入参
字段名称	类型	描述	是否必须
Content-Type	String	application/json	Y
Authorization	String	token	Y
3.4 请求入参
字段名称	类型	描述	是否必须
longitude	String	经度	Y
latitude	String	纬度	
startDate	String	起始日期（YYYY-MM-dd）	
endDate	String	结束日期（YYYY-MM-dd）	
startTemperature	String	起点积温（比如10）	
3.5 接口出参
字段名称	类型	描述	是否必须
code	String	响应编码0 成功，其他均为失败	Y
msg	String	响应描述	Y
data	Json	查询结果	Y
3.6 返回报文样例

    "code": 0,

4. 农场按日期的平均降水和平均日均温接口
4.1 接口描述
根据农场ID，和指定的日期范围，返回按月-日，group average的降水和日均温，如果日期跨度没有超过一年则返回真实数据。用于做气象预测。
4.2 接口URL
https://iland-t.zoomlion.com/open-sharing-platform/zlapi/weather/v1/getAvgTemAndPre
4.3 	请求头入参
字段名称	类型	描述	是否必须
Content-Type	String	application/json	Y
Authorization	String	token	Y
4.4 请求入参
字段名称	类型	描述	是否必须
farmId	String	农场id	Y
startDate	String	起始日期（YYYY-MM-dd）	
endDate	String	结束日期（YYYY-MM-dd）	
4.5 接口出参
字段名称	类型	描述	是否必须
code	String	响应编码0 成功，其他均为失败	Y
msg	String	响应描述	Y
data	Json	查询结果	Y
4.6 返回报文样例
