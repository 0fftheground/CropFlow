# Business Direction Planning

本目录保存 FDE 访谈后沉淀的业务方向接入材料。

目录边界：

```text
1. directions/：业务方向怎么接入，包含范围、任务链路、字段草案、场景和待决问题。
2. team-work-division/：团队角色怎么协作，保留产品 / 架构、核心后端、前端等角色边界和 handoff。
3. guides/：FDE、AI agent、文档整理等方法和流程。
4. archive/：历史阶段材料，不作为默认入口。
```
