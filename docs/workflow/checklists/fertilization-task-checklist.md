# 施肥方向任务清单

1. 土样采集
	- 任务触发条件：种植计划创建时，用户选择新增采土任务
	- 任务作业时间：最晚种植前13天
	- 系统动作：新增土样采集CalendarItem
	- 作业方案：采样点清单
	- 作业流程：系统根据种植计划包含的地块生成采样点、人工执行采土任务、录入作业记录
	- 任务后续操作：生成土样检测任务
	- 接口依赖：采样点规划算法接口
		- 接口调用时间：系统创建采土任务后
		- 接口返回结果：采样点清单
		
2. 土样检测
	- **任务触发条件：土样快递单号上传？**
    - 系统动作：新增土样检测CalendarItem
	- 作业方案：实验室土壤检测标准
	- 作业流程：土壤检测、上传土壤检测结果
	- 任务后续操作：施肥处方生成
  
3. 施肥处方生成
   - **任务触发条件：用户复用历史土壤检测数据或者土样检测结果上传后**
   - 系统动作：新增施肥处方生成CalendarItem
   - **作业流程：1、确定施肥处方算法；2、用户补充算法必须的相关参数；3、调用施肥算法接口获取采样点的基肥、分蘖肥、穗肥的处方，系统根据种植计划的田块范围对没有采样点的田块插值填充各施肥处方；4、人工审核，人工调整施肥量（可选）；5、保存施肥处方**
   - 任务后续操作：生成施基肥CalendarItem、施蘖肥CalendarItem和施穗肥CalendarItem
   - 接口依赖：施肥处方接口

4. 施基肥
   - 任务触发条件：施肥处方生成任务完成
   - 系统动作：生成施基肥CalendarItem
   - 作业方案：
     - 施肥处方：施肥处方生成任务获取
     - 作业时间：农事日历服务根据水稻生育期提供具体的推荐日期范围
   - 作业流程：服务人员到达现场、完成肥料撒施、录入作业记录
   - **任务后续操作：施肥作业效果评估？**

5. 施蘖肥
   - 任务触发条件：施肥处方生成任务完成
   - 系统动作：生成施蘖肥CalendarItem
   - 作业方案：
     - 施肥处方：施肥处方生成任务获取
     - 作业时间：农事日历服务根据水稻生育期提供具体的推荐日期范围
   - 作业流程：服务人员到达现场、完成肥料撒施、录入作业记录
   - **任务后续操作：施肥作业效果评估？**

6. 分蘖末期遥感长势监测
   - 任务触发条件：施肥处方生成任务完成
   - 系统动作：生成分蘖末期遥感长势监测CalendarItem
   - 作业方案：
     - 作业时间：农事日历服务根据水稻生育期提供具体的推荐日期范围
   - **作业流程：服务人员到达现场（可选）、无人机高空拍摄、影像上传和拼接、异常区域和异常点获取、异常点无人机低空拍摄、人工判断异常原因、变量穗肥处方生成**
   - 接口依赖：影像拼接、异常点获取、变量穗肥处方
  
7. 施穗肥
   - 任务触发条件：施肥处方生成任务完成
   - 系统动作：生成施穗肥CalendarItem
   - 作业方案：
     - 施肥处方：分蘖末期遥感长势监测获取变量施肥处方
     - 作业时间：农事日历服务根据水稻生育期提供具体的推荐日期范围
   - 作业流程：服务人员到达现场、完成肥料撒施、录入作业记录
   - **任务后续操作：施肥作业效果评估？**
