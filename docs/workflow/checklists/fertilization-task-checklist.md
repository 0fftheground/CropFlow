# 施肥方向任务清单

1. 土壤采集
	- 任务触发条件：种植计划创建时，用户选择新增土壤采集任务，如果农场没有历史土壤检测数据则必须新增土壤采集任务
	- 任务作业时间：最晚种植前13天
	- 系统动作：新增土壤采集 `CalendarItem`，到期后生成土壤采集 `FarmingTask`；系统生成采样任务id以及各采样点的土样id，采样点默认为种植计划中所有的地块各一个，后续可能会接入采样点规划算法接口来获取采样点
	- 作业方案：采样点清单（id、地块、位置）
	- 作业流程：系统根据种植计划包含的地块生成采样点、人工执行土壤采集 `FarmingTask`、录入作业记录
	- 任务后续操作：生成土壤检测 `CalendarItem`
	- 接口依赖：采样点规划算法接口（后续增加，暂不需要）
		- 接口调用时间：系统创建采土任务后
		- 接口返回结果：采样点清单
		
2. 土壤检测
	- 任务触发条件：土壤采集 `FarmingTask` 已完成
   - 系统动作：新增土壤检测 `CalendarItem`，到期后生成土壤检测 `FarmingTask`
	- 作业方案：实验室土壤检测标准
	- 作业流程：土壤样品验收、土壤检测、上传土壤检测结果
	- 任务后续操作：生成施肥处方生成 `CalendarItem`
  
3. 施肥处方生成
   - 任务触发条件：创建种植计划时用户没有新增土壤采集任务（即复用历史土壤检测数据）或者土壤检测结果上传后
   - 系统动作：新增施肥处方生成 `CalendarItem`，到期后生成对应 `FarmingTask`
   - 作业流程：1、用户选择施肥处方算法；2、用户补充算法必须的相关参数；3、调用施肥算法接口获取采样点的基肥、分蘖肥、穗肥单位面积施肥量，系统侧根据种植计划的田块范围映射 / 补充为地块维度的单位面积施肥量，不要求算法返回地块绝对施肥总量；4、人工审核，人工调整施肥量（可选）；5、保存施肥处方
   - 任务后续操作：生成施基肥 `CalendarItem`、施蘖肥 `CalendarItem` 和分蘖末期遥感长势监测 `CalendarItem`
   - 接口依赖：施肥处方接口

4. 施基肥
   - 任务触发条件：施肥处方生成 `FarmingTask` 完成
   - 系统动作：生成施基肥 `CalendarItem`，到期后生成施基肥 `FarmingTask`
   - 作业方案：
     - 施肥处方：施肥处方生成结果获取
     - 作业时间：调用农事日历接口通过传入水稻生育期等信息获取到具体的推荐日期范围
   - 作业流程：服务人员到达现场、完成肥料撒施、录入作业记录
   - 任务后续操作：生成施肥效果评估 `CalendarItem`

5. 施蘖肥
   - 任务触发条件：施肥处方生成 `FarmingTask` 完成
   - 系统动作：生成施蘖肥 `CalendarItem`，到期后生成施蘖肥 `FarmingTask`
   - 作业方案：
     - 施肥处方：施肥处方生成结果获取
     - 作业时间：调用农事日历接口通过传入水稻生育期等信息获取到具体的推荐日期范围
   - 作业流程：服务人员到达现场、完成肥料撒施、录入作业记录
   - 任务后续操作：生成施肥效果评估 `CalendarItem`

6. 分蘖末期遥感长势监测
   - 任务触发条件：施肥处方生成 `FarmingTask` 完成
   - 系统动作：生成分蘖末期遥感长势监测 `CalendarItem`，到期后生成对应 `FarmingTask`
   - 作业方案：
     - 作业时间：调用农事日历接口通过传入水稻生育期等信息获取到具体的推荐日期范围
   - 作业流程：服务人员到达现场（可选）、无人机高空拍摄、影像上传和拼接、异常区域和异常点获取、异常点无人机低空拍摄、人工判断异常原因、变量穗肥处方生成
   - 接口依赖：影像拼接、异常点获取、变量穗肥处方算法
  
7. 施穗肥
   - 任务触发条件：分蘖末期遥感长势监测 `FarmingTask` 完成
   - 系统动作：生成施穗肥 `CalendarItem`，到期后生成施穗肥 `FarmingTask`
   - 作业方案：
     - 施肥处方：分蘖末期遥感长势监测获取变量施肥处方
   - 作业时间：调用农事日历接口通过传入水稻生育期等信息获取到具体的推荐日期范围
   - 作业流程：服务人员到达现场、完成肥料撒施、录入作业记录
   - 任务后续操作：生成施肥效果评估 `CalendarItem`

8. 施肥效果评估
   - 任务触发条件：施基肥、施蘖肥或者施穗肥 `FarmingTask` 完成
   - 系统动作：新增施肥效果评估 `CalendarItem`，到期后生成对应 `FarmingTask`
   - 任务作业时间：施肥 `FarmingTask` 完成7-10天
   - 作业流程：服务人员到达现场、调查作物长势、录入施肥评估结果
